# 本文小黑手绘配图

本文八张正式PNG，均为1792×1008（16:9）。数字与API来自冻结实验；风格按作者选定的 Ian Xiaohei Illustrations / Ian 规范绘制。

风格来源：https://github.com/helloianneo/ian-xiaohei-illustrations 。本项目以Codex调用图像生成工具逐图绘制；D采用已确认样图，G1/G2的纸面内保留真实终端截图原像素。图像模型没有重画统计或RequestId。

G1/G2截图来自真实终端对保存日志/缓存的只读回放，不是本轮重新调用在线接口。完整记录仍在项目data目录；对应RequestId可与缓存逐项核对。

插画物件的长度、面积和堆叠数量只是隐喻，不作为精确计数或比例尺。可复制的图片校验值见manifest.json。原始插画、提示词、版式SVG和详细自检另存于项目assets/xiaohei-full-redraw；SVG只编辑版式及证据图层，插画本体为位图。

文件顺序A、B、C、D、E、F、G1、G2；正文按叙事顺序编号为图1至图10，其中另保留核验实录和4/9回答级统计图。
